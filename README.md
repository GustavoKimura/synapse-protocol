# Synapse Protocol

Deep simulation sandbox with LLM-driven NPCs possessing emergent consciousness, built with Godot and a modular Python backend.

## Architecture

### Visual Client
- Engine: Godot 4.2
- Language: GDScript
- State Management: Component-based state machines

### Cognitive Backend
- API Framework: FastAPI
- LLM Router: LiteLLM
- Local Execution: Ollama (Native Windows)
- Database: SQLite

### Open Source Assets
- Graphics: Kenney.nl (CC0), OpenGameArt (CC0)
- Audio: Freesound.org (CC0)
